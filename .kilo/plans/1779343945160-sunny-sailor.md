## Admin Panel Structure (Current State)

### Routes
- `/admin/` - Dashboard with stats
- `/admin/enquiries` - Enquiry management
- `/admin/services` - Service CRUD
- `/admin/gallery` - Gallery image management
- `/admin/videos` - Video management
- `/admin/testimonials` - Testimonial management
- `/admin/settings/*` - Settings management
  - `/hero` - Hero text & background images
  - `/home` - Why Us, Process, FAQs
  - `/about` - About page content
  - `/contact` - Contact details
  - `/social` - Social media links
  - `/seo` - SEO settings
  - `/cta` - Call-to-action banner
  - `/footer` - Footer content
  - `/analytics` - GA measurement ID

### Auth & Authorization
- **Login**: `/signin` route with password/magic link auth
- **Role Check**: `useAuth()` hook checks `user_roles` table
- **Auto-role assignment**: First user becomes admin, subsequent users get 'user' role
- **RLS Policies**: All admin routes protected by `has_role(auth.uid(), 'admin')`

## Expected Behavior

### Admin User Journey
1. Visit `/signin`
2. Login with credentials
3. Redirect to `/admin/`
4. View dashboard stats
5. Navigate to any management section
6. Create/edit/delete content
7. Save settings

### Regular User Journey
1. Visit `/` (public home)
2. Browse services, gallery, videos
3. Submit enquiry via `/enquiry`
4. View contact details
5. Note: Cannot access `/admin/*`

### Unauthenticated User Journey
1. Visit `/` - sees public content
2. Visit `/enquiry` - can submit form
3. Visit `/admin/*` - redirected to `/signin`
